Это **локальная тестовая статья** для проверки архитектуры SEO-библиотеки.

## Зачем она нужна

Она позволяет убедиться, что:

- Markdown превращается в HTML;
- каталог показывает карточку с обложкой;
- статическая страница содержит полный текст для индексации;
- кнопка практики ведёт на существующий URL.

## Важно

Файл нужен только для локальной проверки. Перед production-деплоем смените `status` на `draft` или удалите статью из пакета публикации.
