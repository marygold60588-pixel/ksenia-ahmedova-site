# Бесплатный пилот интерактивной практики

Ветка: `feature/interactive-practice-free-pilot`. Маршрут: `/praktika-ne-otkazyvatsya-ot-sebya`.

## Что уже реализовано
- Шесть последовательных вопросов о конкретной ситуации, желании, страхе и реальном поведении другого человека.
- Локальный дневник ситуаций; записи можно просматривать и удалять.
- Предварительная карта с ограниченными правилами, учитывающая ответы и последнюю запись.
- Премиальный интерфейс, интерактивные кнопки, декоративный SVG-узор, опциональный тихий звук, адаптивная вёрстка и reduced-motion.
- Локальная форма обратной связи; экспорт JSON и удаление всех записей.

## Критические ограничения перед публичным запуском
1. **Это прототип без серверного ИИ.** Нельзя рекламировать как адаптивную AI-практику или полноценный психологический анализ.
2. **Нет серверного сбора обратной связи.** Согласие на публикацию не отправляется и не сохраняется отдельно; пользователь может только экспортировать данные.
3. **Нет аналитики воронки этой новой практики.** Нужны события открытия, старта, прохождения, возврата в дневник, отправки отзыва без передачи чувствительных ответов в Метрику.
4. **Нет аккаунта/безопасного серверного хранения.** localStorage подходит лишь для закрытого прототипа, не для обещания конфиденциального дневника; на общем устройстве записи доступны другим пользователям браузера.
5. **Нужно проверить мобильную и клавиатурную доступность, контраст, звук и тексты, провести сборку и тестирование.**
6. **Нельзя сливать ветку в main или деплоить без явного одобрения.**
7. Для AI-функций необходимы согласование бюджета, ограничение запросов, серверный ключ, правила безопасности, согласие на обработку чувствительных данных и возможность их удаления.
8. Окончательная карта должна учитывать весь цикл дневника, а не появляться как окончательный вывод до завершения наблюдений.

## Запуск локально
`npm install`
`npm run build`
`npm run dev`

Сначала проверьте сборку и сценарии, затем готовьте безопасную инфраструктуру для реального бесплатного пилота.
